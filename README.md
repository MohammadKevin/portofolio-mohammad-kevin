## 🚀 Getting Started

### Prerequisites
Make sure you have the required runtimes and tools installed on your machine:
- Node.js (v18+ recommended) / Appropriate runtime
- Git

### Installation & Local Setup
```bash
git clone https://github.com/MohammadKevin/portofolio-mohammad-kevin.git
cd portofolio-mohammad-kevin
npm install
npm run dev
```
